# PPH Jobs Android App

Android WebView wrapper for https://www.peopleperhour.com/freelance-jobs.

This is an independent wrapper and is not an official PeoplePerHour application.

## APK build

GitHub Actions builds a directly installable debug APK and uploads it as the `PPH-Jobs-APK` artifact.

The app supports JavaScript, cookies/session persistence, file uploads, downloads, Android back navigation, and opens non-PeoplePerHour links externally.
